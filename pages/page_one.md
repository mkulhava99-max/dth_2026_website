# Pros of open source

## What are the advantages of open source software?



When people talk about open-source software, the first thing mentioned is usually that it costs nothing to download. While zero price is a huge benefit for students and small organizations, the real strength of open source comes from having full access to the source code.

Because anyone can read and inspect the code, users do not have to blindly trust a software vendor. Security researchers and developers can verify exactly what an application is doing, ensuring there are no hidden tracking tools, privacy violations, or security holes. Code access also lets users modify the software to fit their exact needs. If a feature is missing or broken, a developer can fix or add it themselves instead of waiting for a commercial vendor update.

Another key advantage is duration of the software and vendor independence. When a proprietary company closes down, cancels a product, or raises subscription fees, users are left stuck. With open source, even if the original creator steps away, the software lives on. Anyone can copy the code repository, keep hosting it, and continue maintenance independently.

Different groups benefit from open source in distinct ways:

-	**Students and researchers** get access to tools like LibreOffice without license fees and can study real production code to learn how software is built.
-	**Municipalities and public bodies** follow the principle of "public money, public code," spending tax dollars on local customization rather than software monopolies.
-	**Maintainers** can collaborate globally, solve shared technical problems, and build public digital infrastructure.
