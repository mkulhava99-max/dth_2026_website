# Cons of open source

## *What are the disadvantages of open source software?*

Although open source software is free to download, it is not free to make. Even though I am not a software developer, after attending the class Digital Technologies for Humanities I know that developing a software takes time, the right equipment, and skills. Because many open source tools are built by unpaid volunteers in their spare time, serious operational and security disadvantages can also arise.

One of the biggest issues in open source today is a maintainer burnout. Many popular tools rely on a single tired maintainer looking after a code used by millions of people. If that person burns out or moves on, the project can easily be abandoned. This leaves security holes open and vulnerabilities unaddressed, which could expose everyone who relies on that software.

Open source also shifts technical responsibility directly onto the user:

-	**Hidden support costs:** The license is free, but organizations still pay for deployment, server hardware, user training, and custom integration.
-	**No official support:** If a proprietary tool breaks, you can call customer support or rely on a contract. With open source, you usually rely on public forums, documentation, or issue trackers.
-	**Uneven user experience:** Maintainers often prioritize code functionality over polished design, which is harder to learn for non-technical users.

From a university or municipality perspective, adopting an open source tool without internal technical staff can end up costing more in long-term maintenance than buying a commercial subscription with dedicated support.
