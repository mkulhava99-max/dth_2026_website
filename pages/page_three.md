
# LABEL STUDIO

## *Why Label Studio is a useful open source project for European Studies?*

In Data Science and Machine Learning, high-quality labelled data is essential. **Label Studio**, created by **HumanSignal**, is a data annotation tool that allows researchers to label text, audio, images, video, and time-series data in one place.

For European Studies, it can be useful in projects that work with large text collections or digitized documents. For example, if researchers want to train a model to analyse parliamentary speeches or historical sources, Label Studio can be used to create the training data by manually annotating relevant information. The annotations can then be exported and integrated into a Python workflow. 

**The Five Repository Checks**
1.	*Licence:* Label Studio is released under the Apache 2.0 licence. This means that users are free to use, modify, and distribute the software, including for commercial purposes.
2.	*Last change:* The GitHub repository (HumanSignal/label-studio) is actively maintained. Recent commits show that development is ongoing and that new updates are regularly being added.
3.	*People:* The project has a large user base and receives contributions from both HumanSignal and the wider open-source community.
4.	*Questions:* Users can ask questions and report issues through GitHub. There is also an active Slack community where users can discuss problems and share solutions.
5.	*Money:* Development of the open-source version is supported by HumanSignal, which also offers a paid enterprise version of the software.

### Verdict for a Thesis
I would consider Label Studio a reliable choice for a thesis project. During my student assistant job, I worked with the software while annotating European parliamentary speeches, so I already have practical experience with it. Another advantage is that the platform supports common export formats such as JSON, CSV, COCO, and YOLO. This makes it easy to transfer the data to other tools if necessary and reduces dependence on a single platform.
