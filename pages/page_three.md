
# Label Studio

## *Why Label Studio is a useful open source project for European Studies?*

In Data Science and Machine Learning, high-quality labelled data is essential. **Label Studio**, created by **HumanSignal**, is a data annotation tool that allows researchers to label text, audio, images, video, and time-series data in one place.

In my major, Label Studio helps prepare training datasets for machine learning models. For example, in a document extraction project, I can use Label Studio to outline text bounding boxes on digitized manuscripts and export the annotations directly into a Python data pipeline. 

**The Five Repository Checks**
1.	*Licence:* Label Studio uses the Apache License 2.0. This license lets anyone inspect, modify, distribute, and commercialize the code without paying royalties.
2.	*Last change:* The GitHub repository (HumanSignal/label-studio) is actively maintained, with commits pushed almost daily to the main branch.
3.	*People:* The project has strong community support.
4.	*Questions:* GitHub issues are regularly triaged by HumanSignal engineers, alongside an active community Slack channel for troubleshooting.
5.	*Money:* The open-source core is backed and funded by HumanSignal, which sells an Enterprise version to large companies.

### Verdict for a Thesis
I have already worked with Label Studio at my student assistant job, where I helped coding European parliamentary speeches, and I would confidently rely on Label Studio for my thesis. Standard export formats like JSON, CSV, COCO, and YOLO mean there is zero vendor lock-in. If the project were ever abandoned, I could easily export my data and move to another tool.
